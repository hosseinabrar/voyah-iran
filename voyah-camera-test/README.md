# Voyah Camera Test 0.1.0

پروژهٔ مستقل تست دوربین؛ در Android Studio همین پوشه را باز کنید. SDK محلی را در local.properties یا Android Studio تنظیم کنید. حداقل Android 9 است؛ روی Android 11 خودرو و نسخه‌های جدید قابل نصب است. APK ساخته نشده است.

## روش تست
۱. مجوز دوربین را بدهید.
۲. یک دوربین انتخاب کنید و «نمایش تصویر» را بزنید. انتخاب دوربین قبلی را می‌بندد؛ شروع اتصال صریح است.
۳. مسیرهای فیزیکی در فهرست دوم فقط وقتی نمایش داده می‌شوند که Camera2 آن‌ها را به‌عنوان زیرمجموعهٔ یک دوربین منطقی معرفی کند. این فهرست، فهرست قطعی دوربین‌های آپولو نیست.
۴. بعد از تست موارد مختلف «ارسال گزارش» را بزنید. تمام جلسات ذخیره‌شده در یک فایل متن ارسال می‌شوند؛ با اشتراک فایل گزارش‌های اصلی حذف نمی‌شوند.

لاگ شامل مشخصات سیستم، شناسه‌ها، قابلیت‌ها، اندازه‌های پیش‌نمایش، وضعیت دسترسی، مسیر انتخابی، خطای دوربین و جلسه، زمان اولین فریم و تعداد فریم‌هاست. دریافت فریم الزاماً معنی تصویر سالم ندارد؛ سیاه‌بودن یا محتوای تصویر را هنگام ارسال توضیح دهید. تصاویر و صدا ذخیره نمی‌شوند. جهت تصویر خام حفظ می‌شود و نسبت تصویر کشیده نمی‌شود.

اگر برنامهٔ اشتراک فایل در خودرو ندارید، پس از زدن ارسال گزارش در نسخه debug:

```powershell
./adb exec-out run-as com.abrar.voyahcameratest cat cache/camera-report.txt > camera-report.txt
./adb logcat -d -s VI/CameraProbe > camera-logcat.txt
./adb shell dumpsys media.camera > camera-system.txt
```

فایل داخلی هر جلسه در files/reports قرار دارد. خروجی اشتراک در cache/camera-report.txt است. فایل ممکن است مشخصات مدل و fingerprint سیستم را داشته باشد.

هیچ دستور CAN، تغییر تنظیمات خودرو، توقف سرویس، روت یا اسکن شبکه اجرا نمی‌شود. دوربین‌های متصل صرفاً به ECU دیگر ممکن است به اندروید معرفی نشوند. نبود تصویر دلیل کافی برای عوض‌کردن ID یا خراب‌بودن دوربین نیست. آزمایش در خودرو متوقف انجام شود.

## بررسی انجام‌شده
XMLها بررسی شدند. تلاش برای بررسی مستقل Java به خطای دسترسی ابزار Java به فایل‌های SDK در محیط اجرا خورد؛ صحت بیلد هنوز تأیید نشده است. بیلد Gradle و تست روی خودرو انجام نشده و هیچ APK تولید نشده است.

## گزارش کامل از لپ‌تاپ با Logcat
پیش از بازکردن اپ، دستور زیر را در پوشه ADB اجرا کنید و تا پایان تست باز نگه دارید:

```powershell
./adb logcat -b all -v threadtime '*:V' > camera-full-log.txt
```
بعد از تست دوربین‌ها Ctrl+C بزنید. این فایل علاوه بر تگ VI/CameraProbe شامل لاگ‌های سرویس دوربین اندروید هم هست. فایل را بدون فیلتر ارسال کنید. برای وضعیت کلی هم:

```powershell
./adb shell dumpsys media.camera > camera-system.txt
```
تمام رویدادهای اپ در Logcat ثبت می‌شوند؛ هر رویداد شناسه جلسه، شماره رویداد، شناسه تلاش و زمان uptime دارد. پیام‌های طولانی تکه‌بندی می‌شوند تا قطع نشوند. همه خطاهای Capture ثبت می‌شوند؛ فریم‌های موفق به صورت اولین فریم و هر ۳۰۰ فریم خلاصه می‌شوند تا لاگ بی‌جهت پر نشود. ثبت زنده از قبل اجرای اپ از اتکا به بافر محدود Logcat جلوگیری می‌کند.
