# نسخهٔ ۰.۷ — آموزش آفلاین رها

رابط فعلی جایگزین رابط آزمایش قدیمی شده است: نام تستر، متن فقط‌خواندنی شنیده‌شده، شنود، عمل و پارامترها، امتیاز، تأیید/اصلاح، فهرست فرمان‌ها و اشتراک‌گذاری آموزش‌ها.

- رابط HTML/CSS/JS همراه APK در WebView محلی و محدود اجرا می‌شود؛ سرور، مرورگر خارجی، اینترنت و Web Speech API لازم نیست. میکروفون با SpeechLab و Vosk حالت CAR_LIVE بومی اندروید کار می‌کند.
- موتور و مدل مهروموم‌شده از همان ماژول‌های پروژهٔ اصلی می‌آیند؛ هنگام ساخت، آخرین آموزش‌های منتقل‌شدهٔ پروژه بسته‌بندی می‌شوند. TesterModel فقط در اپ تست نامزد برتر و پارامترها را حتی زیر آستانهٔ اجرا نمایش می‌دهد؛ سیاست اجرای محصول تغییر نکرده و این اپ هیچ فرمان خودرویی اجرا نمی‌کند.
- امتیاز نمایشی ۱۰۰ سبز، کمتر از آن نارنجی و UNKNOWN همیشه قرمز است. اصلاح شخصی برای همان جمله و همان نسخهٔ مدل، با برچسب خودش اعمال می‌شود؛ وزن مدل روی گوشی آموزش داده نمی‌شود.
- اصلاحات در فضای خصوصی برنامه، اتمیک ذخیره می‌شوند. فایل JSONL خروجی شامل شناسهٔ دستگاه/رکورد، نام، متن، عمل، پارامترها، مدل و نتیجهٔ اولیه است؛ صوت ذخیره یا ارسال نمی‌شود. پس از اشتراک‌گذاری چیزی حذف نمی‌شود، چون Android تحویل واقعی به تلگرام را تضمین نمی‌کند.
- دکمهٔ اشتراک‌گذاری از ACTION_SEND و FileProvider با مجوز موقت خواندن استفاده می‌کند. گیرنده می‌تواند تلگرام یا هر برنامهٔ اشتراک‌گذاری فایل باشد.
- فایل‌ها با `raha-tester-server/import_reviewed.py` پس از بررسی و انتخاب شناسه‌ها وارد نسخهٔ شخصی می‌شوند. واردکننده تکرارزدایی خودکار ندارد؛ رسید شناسه‌های واردشده را نگه دارید.
- نمونه‌های قدیمی voice-feedback.json عمداً روی دستگاه حذف نمی‌شوند، ولی رابط جدید فقط اصلاحات ساختاریافتهٔ tester-training.json را صادر می‌کند.
- بررسی کامپایل: `ANDROID_HOME=... bash gradlew :app:compileDebugKotlin --offline`؛ آزمون پل رابط: `node test-trainer-ui.mjs`. این بررسی‌ها جای تست میکروفون و اشتراک‌گذاری روی گوشی را نمی‌گیرند.
