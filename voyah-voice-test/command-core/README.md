# Persian command core

کتابخانهٔ مستقل Kotlin/JVM برای تبدیل متن فارسی به فرمان ساخت‌یافته. هیچ وابستگی به Android، Vosk، میکروفون یا ارتباط خودرو ندارد و هیچ فرمانی اجرا نمی‌کند.

```kotlin
val recognizer = PersianCommandRecognizer()
when (val result = recognizer.recognize("لطفا پنجره راننده رو باز کن")) {
    is Recognition.Matched -> {
        val command = result.command
        // action: window.position.set
        // parameters: {window=driver, position=open}
        // Use action and parameters for integration; description is display text.
    }
    is Recognition.Unknown -> { /* Show نامفهوم */ }
}
```

نام دقیق کلیدهای پارامترها را در قواعد و تست‌ها بررسی کنید؛ قرارداد خروجی هنوز آزمایشی است. شناسهٔ catalogId به ردیف فایل تحقیق اشاره دارد.

## استفاده در پروژهٔ اصلی

این ماژول از همین حالا یک کتابخانهٔ JVM است. پوشهٔ `command-core` را به پروژهٔ مقصد منتقل کنید، در settings عبارت `include(":command-core")` و در dependencies ماژول مصرف‌کننده `implementation(project(":command-core"))` را اضافه کنید. پلاگین `org.jetbrains.kotlin.jvm` باید در پروژهٔ مقصد نیز با نسخهٔ سازگار تعریف شود. امکان انتشار JAR به مخزن Maven بعداً وجود دارد؛ نیازی به انتقال Activity یا موتور صوتی نیست. خروجی JVM 17 است.

فقط متن **نهایی** تشخیص صوت را وارد کنید. متن موقت ممکن است با ادامهٔ جمله تغییر کند. اجرای واقعی و بررسی وضعیت خودرو مسئولیت مصرف‌کننده است.

## دامنه و قواعد

- فقط ۴۶ ردیف زرد فایل تحقیق پشتیبانی می‌شوند؛ snapshot انتخاب‌ها در `../research/supported-command-selection.json` است.
- واژه‌های فارسی و اعداد نرمال می‌شوند؛ قواعد عمل، هدف و پارامتر را استخراج می‌کنند. هدف صریح بر هدف پیش‌فرض مقدم است؛ پنجره بدون تعیین سمت به همهٔ پنجره‌ها اشاره می‌کند.
- جمله باید دقیقاً به یک فرمان برسد. چند فرمان هم‌زمان، نفی، سؤال، هدف متناقض و واژه‌های معنادار مصرف‌نشده پذیرفته نمی‌شوند.
- این یک مفسر قواعد محدود است؛ درک عمومی زبان یا تصحیح خطای تشخیص صوت ندارد. مترادف‌های جدید باید همراه تست افزوده شوند.
- برای محدودکردن دامنه، مجموعهٔ شناسه‌ها را به سازنده بدهید: `PersianCommandRecognizer(setOf("VC047"))`.

تست‌های JUnit در `src/test` شامل نمونهٔ تمام ردیف‌های انتخاب‌شده، مترادف‌ها، هدف‌ها، اعداد و موارد ردشدنی هستند. اجرای معمول: `gradlew :command-core:test`؛ APK تولید نمی‌کند.
