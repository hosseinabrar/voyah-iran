# فهرست اولیهٔ فرمان‌های صوتی FREE 318

فایل `voyah-free-318-voice-command-catalog-fa.csv` شامل **۷۶ خانوادهٔ فرمان در ۲۷ دسته** است. بعضی ردیف‌ها مانند روشن/خاموش چند فرمان را در یک الگو جمع کرده‌اند؛ تعداد ردیف‌ها تعداد عبارت‌های گفتاری نیست.

منبع اصلی دفترچهٔ رسمی چینی **FREE 318 / H97D** و فصل‌های مرتبط همان دفترچه است. این فهرست نمونه‌های مستند و پیشنهادهای نگاشت ماست، نه ادعای استخراج همهٔ فرمان‌های OEM از کد یا تضمین پشتیبانی تک‌تک نسخه‌های وارداتی. در بررسی اولیهٔ assetهای SoulMate و AIS، فهرست متنی آمادهٔ فرمان‌ها پیدا نشد؛ مدرک ردیف‌های فعلی از دفترچه است.

- «نمونهٔ صریح فرمان در دفترچه»: عملیات در بخش مثال‌های دستیار آمده؛ متن فارسی ترجمهٔ لفظی اجباری نیست و برای پروژه پیشنهاد شده است.
- «قابلیت صوتی در فصل مربوطه»: دفترچه کنترل صوتی این قابلیت را ذکر می‌کند؛ تمام پارامترها و ترکیب عبارت‌های پیشنهادی نیازمند تطبیق جداگانه‌اند.
- «پیشنهاد پروژه»: برای این مورد پشتیبانی صوتی OEM احراز نشده است.

`action_id`ها و JSONها قرارداد پیشنهادی خودمان‌اند؛ نام متد OEM، مقدار CAN یا API آمادهٔ اجرا نیستند. جای‌خالی‌های داخل آکولاد باید بعداً از متن تشخیص داده شوند؛ به‌عنوان نمونه، مقدار `{true|false}` هنوز بولین نهایی نیست. «بیشتر/کمتر» و «باز/بسته» دو انتخاب‌اند، نه کلماتی که با اسلش تلفظ شوند.

مثلاً پس از پیاده‌سازی نگاشت، «اکو» می‌تواند خروجی نمایشی `drive.mode.set` با پارامتر `mode=eco` تولید کند. در این مرحله CSV فقط سند برنامه‌ریزی است و موتور تست هنوز این نگاشت را اجرا نمی‌کند.

برای شروع تست نگاشت، درایو مود، موسیقی، تنظیم صدا و بازکردن صفحه‌ها نقطهٔ شروع ساده‌ای هستند. فرمان‌های مقصد، مخاطب و نام آهنگ به استخراج متن آزاد نیاز دارند؛ صرف تطبیق یک کلمه برایشان کافی نیست. تشخیص آفلاین فارسی نیز به‌تنهایی به معنی آفلاین‌بودن جست‌وجوی موسیقی، ترافیک یا نقشه نیست.

فایل با **UTF-8 BOM** و جداکنندهٔ کاما ذخیره شده تا فارسی در Excel درست دیده شود. اگر ستون‌ها جدا نشدند، از Data → From Text/CSV با Encoding UTF-8 و Delimiter Comma وارد کنید.

در فایل CSV، آدرس منبع کنار هر ردیف آمده است. مرجع اصلی:
https://m.dsmp.voyah.com.cn/userguide/h97d/h97D-8.html

تعداد ردیف‌ها، یکتایی شناسه‌ها و معتبر بودن JSON پارامترهای هر ردیف بررسی شده‌اند.
